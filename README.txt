ÉDIFICE CONCEPT BTP — Prototype V1

Contenu:
- index.html : plateforme responsive
- logo-edifice.png : logo extrait de l'image de référence fournie

Fonctions:
- Accueil professionnel
- 3 parcours: chercher un logement, proposer un bien, construire
- Formulaires de manifestation d'intérêt
- Tableau local des demandes
- Sauvegarde locale dans le navigateur (localStorage)
- Design mobile et ordinateur

Limite importante:
Cette V1 est un prototype local. Les demandes ne sont pas encore transmises à un serveur, WhatsApp, e-mail ou une base de données distante.

Prochaine étape pour une vraie mise en production:
1. Base de données sécurisée
2. Espace administrateur avec authentification
3. Notifications WhatsApp/e-mail
4. Gestion des biens avec photos et statut
5. Hébergement avec nom de domaine
